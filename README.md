# GK - Assistant Tutorat (iiAfrica Edition)

An evolutionary, bilingual (FR/EN) desktop application developed to manage and track the progress of multiple learners (apprentices and interns) within the framework of **iiAfrica** (Innovative Institute for Africa).

## 🚀 Features
* **Bilingual Interface**: Quick toggle between French 🇫🇷 and English 🇬🇧.
* **Mentor Space**: Dedicated area to log training notes, program syllabi, and pedagogical methods.
* **Mentees Tracking**: Structured sections for daily logbooks, skills matrices, and monthly goals.
* **Scalable Management**: Dynamically add and manage up to 10+ learners.
* **Data Privacy**: 100% local database storage (SQLite) protecting learner confidentiality.
* **Excel Export**: Generate automated `.csv` reports for school coordinators and reviews.

## 🛠️ Tech Stack
* **Language**: Python 3
* **GUI Framework**: Tkinter (Native Windows rendering)
* **Database**: SQLite3 (Local file-based system)
* **Compiler**: PyInstaller (Standalone executable deployment)
